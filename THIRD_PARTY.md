# Third-party parts in Mystik

- **CLAP headers** (`third_party/clap/`): the CLAP plug-in API, MIT. Licence text in
  `third_party/clap/LICENSE`.
- **`src/melodee_screen.h`**: Melodee's plug-in screen extension header, MIT (its SPDX header
  says so, so any plug-in may copy it).
- **Departure Mono glyphs** (`src/ui/font.h`): the page's font, SIL Open Font License.
  Licence text in `licenses/OFL-departure-mono.txt`.

Everything else in this repository is Mystik's own. The gate follows Parker and D'Angelo's
published model (DAFx-13, cited with the inferred values in the README); no code is taken
from it. There is no project licence yet (see the README).
